# Contributing

Thank you for helping improve CapTrace.

1. Open an issue describing the bug or proposed scenario.
2. Keep scenario fixtures deterministic, offline, and self-contained.
3. Run `python -m unittest discover -s tests -v` and `captrace --policy runtime`.
4. Submit a pull request explaining the expected policy result and why.

Avoid claims of real-world security guarantees. Test only systems you are
authorized to test. No proprietary model prompts, personal data, or credentials.
